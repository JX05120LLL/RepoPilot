## 架构取舍

RepoPilot 借鉴 Grok Build 的职责分层，而不复制其源码或迁移至 Rust：

```text
Tauri Desktop / CLI / Controlled Terminal
                |
       Local FastAPI + SSE
                |
Task Service + LangGraph Orchestrator
                |
Context Broker + Capability/Trust Gateway
                |
Workspace / Git / Patch / Maven / MCP Runtime
                |
SQLite + Qdrant + JSONL + Artifact Directory
```

- LangGraph 只负责流程编排，不能获得文件系统、进程或网络的绕过权限。
- PolicyGuard 和 ToolRuntime 位于图外的强制边界，模型、Skill、MCP 输出和 RAG 文本均不能修改权限快照。
- SQLite 保存任务事实、恢复状态和产物元数据；Qdrant 保存可按项目/提交过滤的代码、文档和已验证记忆，不替代任务状态库。

## 设计预留，不应视为已交付

- 任意 Shell、任意网络访问、删除、`git commit/push` 和直接绕过受控补丁的源仓库写入。
- Windows 安装包代码签名、自动更新、生产级数据库、用户账号与团队协作。
- MCP OAuth、持久连接池、服务级配额，以及 Skill 脚本执行器。
- PDF/DOCX 解析、Java AST/符号索引、BM25/重排、子 Agent 与 IDE Adapter。
- 15 项任务在真实模型配置下的持续回归基准与成本报表。
